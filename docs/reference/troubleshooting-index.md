# 排障索引

## 通用排障顺序

确认现象、记录时间和请求标识，再检查配置、网络、依赖、日志、指标和最近变更。每次只改变一个变量。

## 计划索引

- HTTP 状态码：计划中。
- JWT 校验失败：计划中。
- Webhook 未到达：计划中。
- ETL 数据重复：计划中。
- RAG 答案无依据：计划中。
- Agent 工具调用失败：计划中。
