# 架构师交付物

| 交付物 | 用途 |
| --- | --- |
| 需求清单 | 记录目标、范围、优先级和验收条件。 |
| 上下文图 | 说明系统与用户、外部系统的边界和关系。 |
| 接口清单 | 记录调用方、被调用方、协议、数据和失败处理。 |
| 数据流图 | 说明数据从产生到使用、存储和删除的路径。 |
| 风险登记表 | 记录风险、概率、影响、负责人和应对措施。 |
| ADR | 记录一个重要架构决策、选项和取舍。 |
| Runbook | 记录运行、排障、恢复和升级步骤。 |
| 现状系统清单 | 记录系统用途、所有者、数据、接口和运行限制。 |
| 现状流程 | 记录真实步骤、交接、等待、例外和返工。 |
| 问题日志 | 分开记录事实、假设、冲突和待回答问题。 |
| 需求交付包 | 将目标、利益相关者、现状、用例、需求、范围、验收、风险和决定关联起来，供设计、测试和业务评审使用。 |
| 范围基线 | 经授权者确认的首期交付范围、排除项、假设和验收条件版本，用作变更影响评估的参照。 |
