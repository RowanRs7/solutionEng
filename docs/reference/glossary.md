# 术语表

| 术语 | 定义 |
| --- | --- |
| 解决方案 | 针对业务目标的一组技术、流程和交付安排。 |
| 解决方案架构 | 描述组件、边界、关系、约束和关键决策的设计。 |
| 利益相关者 | 受方案影响、能够影响方案或拥有关键信息的人或组织。 |
| 业务目标 | 组织希望通过行动取得的结果。 |
| 产出 | 项目直接交付的产品、功能或文档。 |
| 成果 | 产出被使用后带来的可观察变化。 |
| 指标 | 用于判断目标或质量是否达成的可测量值。 |
| 约束 | 限制方案选择或交付方式的条件。 |
| 假设 | 尚未验证、但当前方案暂时依赖的判断。 |
| 交付物 | 生命周期某阶段产生并交给他人使用的结果。 |
| 验收标准 | 用于判断某项需求是否完成的可验证条件。 |
