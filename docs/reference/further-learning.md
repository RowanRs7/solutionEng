# 延伸学习

不用从头到尾按顺序学。先看当前项目最卡的是哪一块，再挑对应方向补，学完能马上用上才记得住。

## 推荐方向

- 网络与后端：HTTP、TLS、数据库、消息和容器。适合“接口能通，但一慢一挂就说不清原因”的时候补，重点是搞懂请求在路上经历了什么。
- 架构与交付：C4、ADR、容量、可靠性和云平台。适合要从“写功能”转到“定方案”的时候补，重点是学会画清边界、记录取舍。
- AI 工程：模型服务、检索、工具调用、评测和治理。适合做 AI 应用却总在效果和成本之间来回救火的时候补，重点是建立可验证的评估习惯。
- 业务与交付：需求访谈、价值指标、风险和变更管理。适合技术没问题、但方案总被业务方打回的时候补，重点是听懂“他真正想要什么”。

选择延伸材料时，优先读官方文档、标准和协议原文，多做能复现的实验。模型和框架变化快，看到具体结论时顺手记下访问日期和版本，下次才不会拿旧信息当真。
