# 延伸学习

## 推荐方向

- 网络与后端：HTTP、TLS、数据库、消息和容器。
- 架构与交付：C4、ADR、容量、可靠性和云平台。
- AI 工程：模型服务、检索、工具调用、评测和治理。
- 业务与交付：需求访谈、价值指标、风险和变更管理。

选择延伸材料时，优先阅读官方文档、标准、协议和可复现实验。对于快速变化的模型和框架，记录访问日期和版本。
