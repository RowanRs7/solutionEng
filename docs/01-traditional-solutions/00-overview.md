# 传统解决方案知识体系

## 为什么先学传统工程

AI 应用仍然运行在真实的软件系统中。它需要网络传输、API、身份认证、权限控制、数据同步、异步处理、测试、部署和监控。模型回答得再好，若权限传递错误、Webhook 重复处理或数据管道失效，方案仍会失败。

> **核心结论：** AI 能力建立在传统工程能力之上，而不是替代它。

## 模块路线

本模块完整走过解决方案生命周期：

1. 需求发现与定义。
2. Web 与网络。
3. API 与系统集成。
4. 身份、权限与安全。
5. 数据与应用架构。
6. 开发、测试与交付。
7. 运行与持续优化。

## 完成标准

完成本模块后，学习者应能把业务目标转化为可验证需求，选择常见集成和安全机制，并说明部署、运行和故障恢复方案。

从[需求发现与定义](01-discovery-and-requirements/00-overview.md)开始。

需求发现单元会产出可测量的**验收标准**；完成八篇课程后，使用 `09-stage-assessment.md` 检查掌握程度。
