# 身份与安全阶段综合测评

## 学习目标

本测评检查你能否把认证、凭据、令牌、联邦身份、权限模型、密钥与数据保护串成一条可评审的设计链。建议闭卷答题，再用评分表自评。

- 判断故障落在认证、授权、审计还是数据保护哪一层，给出正确的状态码与日志字段。
- 为员工、顾客、企业客户与系统四类主体选凭据与流程，说清各自的失效场景。
- 把“登录了所以能做”改写成含租户、对象与条件的规则，并交出带证据的设计基线。

## 知识检查清单

- [ ] 能区分认证、授权与审计的问题，说清 `401`、`403` 的适用条件。
- [ ] 能说明密码存储三要素，为不同入口选第二因素与 Session 策略。
- [ ] 能按“结构 → 算法白名单 → 验签 → 声明 → 授权”校验 JWT，说出三种吊销手段。
- [ ] 能判断该用授权码加 PKCE 还是客户端凭证，说明 `state` 与 PKCE 各防什么。
- [ ] 能列出 ID Token 必校验声明与顺序，用 `iss` + `sub` 关联账号。
- [ ] 能写出 SAML SP 侧七项校验，区分 SSO 与 SCIM 的职责。
- [ ] 能解释角色爆炸根因，坚持租户判定先于角色。
- [ ] 能画出主密钥与数据密钥层次，说明轮换完成的判定标准。
- [ ] 能对注入、越权、SSRF、凭据填充各给一项有效控制与一项不够的控制。
- [ ] 能按泄露影响、可见范围与保留期限分级，说明脱敏须在服务端执行。

## 概念题

共 18 题 40 分：1–10 为四选一，每题 2 分；11–18 为简答，每题 2.5 分。先独立作答，再对答案。

1. 【认证/授权/审计】客服已登录但访问他人订单被拒，正确响应是：
   A. 200 与空数据　B. 401 要求重新登录　C. 403 且不透露资源是否存在　D. 500
2. 【凭据与 MFA】下列哪一组属于两个不同性质的因素？
   A. 密码 + 密保问题　B. 密码 + 短信验证码　C. 两个不同的密码　D. 指纹 + 面容
3. 【JWT】资源服务校验 JWT 的正确顺序是：
   A. 解出 payload → 读角色 → 验签
   B. 校验 `exp` → 验签 → 读 `alg`
   C. 结构 → 算法白名单 → 用 `kid` 验签 → 声明 → 授权
   D. 验签 → 用 payload 里的 `roles` 定权限
4. 【OAuth 2.0】一个无法保管密钥的移动 App 代表员工调用退款 API，应选：
   A. 隐式流程　B. 授权码 + PKCE　C. 客户端凭证　D. 资源所有者密码凭据
5. 【OIDC】ID Token 的 `aud` 声明回答的是：
   A. 这个用户是谁　B. 这个令牌发给哪个客户端　C. 令牌何时过期　D. 用户以何种方式认证
6. 【SAML】SP 收到断言后，用于确认“这条断言回应的是我发起的那次登录”的字段是：
   A. `NameID`　B. `AudienceRestriction`　C. `InResponseTo`　D. `NotOnOrAfter`
7. 【RBAC/ABAC】角色数量超过用户数量的根本原因通常是：
   A. 用户增长太快　B. 用角色表达金额、归属等资源属性　C. 没有使用 ABAC 引擎　D. 缺少权限审批
8. 【密钥管理】判断一次密钥轮换真正完成的标准是：
   A. 新密钥已生成　B. 新密钥已下发到所有实例　C. 旧密钥已失效且旧值请求被拒绝　D. 监控显示无告警
9. 【Web/API 攻击】对 SSRF 最有效的控制组合是：
   A. 只允许 `https://` 前缀
   B. 校验协议、主机与 DNS 解析后的地址，禁用自动重定向并统一出口
   C. 用正则屏蔽 `127.0.0.1`
   D. 前端限制输入长度
10. 【数据保护】对“客服在列表页看不到完整手机号”这一要求，正确的实现位置是：
    A. 前端模板　B. CDN 规则　C. 服务端按角色投影后再返回　D. 数据库字段改名

11. 【认证/授权】客服越权访问他人订单，应该返回 403 还是 404？说明判断依据，以及无论选哪个都必须做的一件事。
12. 【凭据】TOTP 与 Passkey 都能做第二因素，为什么只有 Passkey 被认为抗钓鱼？
13. 【JWT】JWT 是无状态的，但业务要求“封号后 1 分钟内全部令牌失效”。给出三种可行手段并说明各自代价。
14. 【OAuth/OIDC】`state` 与 `nonce` 分别防什么？为什么不能互相替代？
15. 【OIDC】账号关联为什么必须用 `iss` + `sub`，而不能用 `email`？
16. 【SSO】SAML/OIDC 与 SCIM 各解决什么问题？只做前者会留下什么后果？
17. 【权限模型】多租户系统中为什么租户判定必须早于角色判定？数据层兜底又防的是什么？
18. 【数据保护】加密、展示脱敏、令牌化、哈希各防住什么、防不住什么？各举一例。

## 常见错答分析

| 高频误解 | 为什么错 | 正确理解 |
| --- | --- | --- |
| “登录成功，接口就该放行；按钮藏起来就是权限控制。” | 认证只证明身份，授权要判断“这个主体对这条记录能做这个动作”。前端隐藏只是体验，直接调接口即可绕过。 | 每个请求都在拥有资源的服务里做对象级判定，数据层再追加归属条件；默认拒绝，拒绝也留审计。 |
| “ID Token 也是 JWT，直接拿去调 API；access token 能证明用户是谁。” | 两者受众不同：ID Token 写给客户端，access token 写给资源服务器，混用等于信任了不该信任的令牌。 | ID Token 只用于建立登录态，access token 只用于调资源；校验时比对 `aud`、`iss`。 |
| “生成新密钥就算完成轮换；页面打码就算完成脱敏。” | 两者都把手段当成结果：旧值仍可用，泄露的凭据就继续有效；原值仍在响应里，调接口就能拿全量。 | 轮换以旧值被拒绝为准；脱敏以响应体不含原值为准，在服务端按角色投影。 |

## 场景分析

> 本测评刻意换用与晴空商城不同的场景，检验你能否把本单元方法迁移到新业务；每问括号内标注对应的课程，评分时按同样标准。

「康桥健康」把体检预约与报告查询做成多租户 SaaS，按企业客户售卖。企业 HR 用自家 IdP 登录，管理本企业员工名单、套餐额度与账单；员工用手机号加短信验证码登录（名单由 HR 导入），也可走企业 SSO；医生在内网工作站录入并签发报告；客服处理加项、改期与费用争议。报告含影像与诊断结论，属敏感个人信息，监管要求访问与导出留痕 3 年。客户要求“员工离职当天就登不进来”；平台 60 天后上线，后端只有两人；支付商要求回调验签。

1. 为 HR、员工、医生、客服各选一种主认证方式与第二因素，并各说一项失效场景。（对应：认证、授权与审计；密码、MFA、Session 与 API Key）（8 分）
2. A 客户只支持 SAML。列出 SP 必须校验的项；“离职当天登不进来”该由哪条通道保证，为什么单点登出不够？（对应：SSO、SAML 与企业身份接入）（8 分）
3. 员工查询报告接口如何同时满足 RBAC、ABAC 与租户隔离？写出判定顺序、拒绝码和五个审计字段。（对应：RBAC、ABAC 与多租户权限）（8 分）
4. 指出最可能的两类攻击，各给一项有效控制与一项“看着有用但不够”的控制。（对应：常见 Web/API 攻击与安全设计）（6 分）

## 参考答案与解析

### 概念题答案

1. C。已认证但无权是授权失败，应返回 403；401 会让客户端误判凭据失效，响应也不应暗示订单存在。
2. B。知识加持有；密保问题同属知识，指纹与面容同属生物特征。
3. C。先结构、再算法白名单、用 `kid` 验签，最后才读声明；颠倒顺序等于把未验证数据当事实。
4. B。用户在场且客户端保不住密钥，授权码加 PKCE 既绑定发起方，又不需要 `client_secret`。
5. B。`aud` 限定令牌接收方，防止别处签发的令牌在本应用登录成功。
6. C。`InResponseTo` 是本次 AuthnRequest 的 ID，SP 要与自己发出的值比对。
7. B。用角色承载金额、归属等属性，只能为每种组合新建角色，角色数最终超过用户数。
8. C。轮换完成的标准是旧值被拒绝，而非新值已生成或下发。
9. B。协议、主机与解析地址三查，并逐跳校验重定向、统一出口，才挡得住 DNS 重绑定。
10. C。脱敏须在服务端投影后返回，直接调接口就绕过页面。
11. 身份有效但无权应返回 403；若资源对主体完全不可见且需防枚举，可用统一 404。无论选哪个，审计都要记真实原因码。
12. TOTP 由共享种子算出，钓鱼站点可实时转发验证码；Passkey 用设备私钥签挑战值，私钥不出设备且绑定源站。
13. 缩短有效期，代价是刷新更频繁；`ver` 自增并写共享存储，代价是每请求查状态；`jti` 写黑名单直到过期，代价是存储与清理。
14. `state` 绑定回调与本次会话，防别人把授权码塞进你的回调；`nonce` 绑定登录请求与 ID Token，防旧令牌重放。两者作用域不同，不能互替。
15. `email` 可改、可回收、可能未验证，用它关联会把两个人并成一个账号；`iss` + `sub` 稳定唯一，`iss` 还能区分身份源。
16. SAML/OIDC 解决“怎么登录、这次是谁”，SCIM 解决“账号何时存在、属于哪个组”。只做前者，离职后本地账号与残留会话仍在。
17. 租户是数据边界，先判租户可保证角色配错也看不到别家数据；先判角色会把“持有跨租户角色”误当租户校验通过。数据层兜底防应用层漏写。
18. 加密防介质与备份被拷走，防不住有解密权限的 DBA；脱敏防截图，防不住调接口；令牌化防信息拼图，防不住映射表被拿走；哈希防原值比对，防不住低熵值穷举。

### 场景分析参考思路

- 认证选型：HR 走企业 IdP 并强制 MFA，令牌留在后端；员工用短信验证码起步、引导 Passkey，失效场景是换号与出境；医生用目录账号加硬件密钥并限定内网；客服走 SSO 加短闲置超时。
- SP 七项：签名与证书、签发者、受众、时间、`InResponseTo`、`Recipient`、断言 ID 是否用过。“离职当天登不进来”靠 SCIM 停用、登录校验 `active` 与每日对账；SLO 只是体验，用户关页面或 IdP 未广播时均不生效。
- 授权链：验签取可信 `sub` 与 `tenant` → 固定租户上下文 → 功能级校验 → 租户先于角色 → RBAC 展开“报告:read” → ABAC 判归属（本人、经授权医生、HR 仅看聚合）→ 数据层追加条件 → 出口按级别投影。403 无权，404 用于跨租户防枚举。审计至少含请求 ID、主体、租户、动作、资源、决定、原因码、时间。
- 两类攻击：越权读报告，有效控制是对象级授权加数据层过滤与负向测试，不够的是隐藏入口或随机化主键；凭据填充，有效控制是按账号限速、泄露口令校验与高风险 MFA，不够的是只按 IP 限速。

### 交付物参考结构

| 表 | 参考内容 |
| --- | --- |
| 主体—凭据—令牌 | 员工：短信验证码 → Passkey，`HttpOnly` 会话 30 分钟闲置过期，删会话即吊销；医生：目录账号 + 硬件密钥；HR：断言换本地会话；系统：客户端凭证 15 分钟令牌。 |
| 授权判定链 | 认证 → 租户 → 功能级 → 角色 → 属性 → 数据层；401/403/404 分明；每步写审计字段与策略版本。 |
| 数据分级 | 报告正文与影像极敏感，仅本人与签发医生见原值，HR 只看聚合；手机号敏感，列表页中部掩码；到期删除并留证据。 |
| 密钥清单 | TLS 证书 90 天自动续期；SAML 签名证书双证书过渡；回调验签密钥 180 天双写窗口；对象存储数据密钥由 KMS 封装。 |
| 风险与证据 | IdP 证书轮换致登录中断：双证书并演练；跨租户越权：负向测试与审计抽样；短信不可达：备用核验流程。 |

合理答案可有不同选择，但必须标出未确认的取值与责任人，不能用“已加密”“已授权”这类无法核验的表述结案。
