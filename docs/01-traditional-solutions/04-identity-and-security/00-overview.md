# 身份、权限与安全

## 单元目标

先别急着背协议名。想象一栋写字楼：进门要刷工牌（证明你是谁），不同楼层权限不同（决定你能去哪），大厅和走廊有监控（记录你实际去过哪）。身份与安全设计要回答的，就是这三个朴素问题：**谁在什么条件下，能对什么数据做什么事，事后能不能说清楚。**

这个单元不会只讲“怎么加登录框”。你会依次弄懂认证、授权与审计的分工，认识 JWT、OAuth 2.0、OIDC 与 SSO 这些常见机制的适用边界，再走到权限模型、密钥管理和数据保护。学完之后，你能为一条真实业务链路画出身份流转图与权限矩阵，并且每个安全决策都能说出“为什么这样选、放弃了什么”。

## 学习路线

预计学习时间为 **8–10 小时**。建议按顺序推进：每课先读完正文、跑通练习，再进入下一课。顺序不是形式主义——后面的 JWT、OAuth、OIDC 都建立在前面“身份与凭据”的概念上。

1. [认证、授权与审计](01-authentication-authorization-and-audit.md)：先把三件事分开，知道一次故障该去哪个环节找原因。
2. [密码、MFA、Session 与 API Key](02-passwords-mfa-session-and-apikeys.md)：看清四种凭据各自代表谁、能活多久、泄露后怎么收回。
3. [JWT 结构、签发与校验](03-jwt-structure-and-validation.md)：理解令牌为什么“能看见内容”却不等于“可信”，以及校验顺序为何不能乱。
4. [OAuth 2.0 授权流程与 PKCE](04-oauth2-flows-and-pkce.md)：学会把权限借给第三方，而不把密码交出去。
5. [OpenID Connect 与身份令牌](05-openid-connect-and-id-tokens.md)：在 OAuth 之上补上“这次登录的人是谁”。
6. [SSO、SAML 与企业身份接入](06-sso-saml-and-enterprise-identity.md)：对接客户的身份系统，管好账号从入职到离职的一生。
7. [RBAC、ABAC 与多租户权限](07-rbac-abac-and-multi-tenant-permissions.md)：从“岗位能不能做”走到“这一条数据能不能动”。
8. [Secret、证书与密钥管理](08-secrets-and-key-management.md)：把钥匙放到保险柜，并演练换锁与丢钥匙。
9. [常见 Web/API 攻击与安全设计](09-web-api-attacks-and-secure-design.md)：看懂注入、越权、SSRF 与撞库是怎么发生的。
10. [数据分类、脱敏与合规基础](10-data-classification-encryption-and-compliance.md)：给数据分级，决定谁能看原值、多久必须删。
11. [身份与安全阶段综合测评](11-stage-assessment.md)：把十课串成一份可评审的设计基线。

## 贯穿场景

晴空商城的退款一直由客服手工处理：客服后台要调用订单服务查询、调用支付渠道发起退款，还要留痕以备对账与审计。这条链路像一栋需要多次刷卡的办公楼：客服要先证明自己是谁，系统要判断这张单归不归他管、金额有没有超限，服务之间还要用另一套“内部通行证”通信，最后每个动作都得留下可回放的记录。

它把本单元的知识点全串起来了：客服与系统之间如何认证、服务之间用什么凭据、退款接口对第三方开放到什么粒度、哪些角色可以批准超额退款、密钥泄露会波及哪些数据。你会围绕同一条退款链路，逐课补齐身份、令牌、授权与数据保护的设计。

## 怎么读这一单元

- **先记生活对应，再记术语。** 工牌≈认证，楼层权限≈授权，监控录像≈审计；酒店房卡≈会话，防伪封条≈签名，寄存柜取件码≈授权码。类比只帮你建立第一印象，每课都会说明它对应到哪里、在哪里失效。
- **每课都动手。** 代码只用 Python 标准库，离线可跑，重点是让你亲眼看到“少校验一步会发生什么”，而不是背结论。
- **把“拒绝”当正常结果。** 安全设计里，默认拒绝是起点；能解释一次拒绝，比能放行一百次更有价值。
- **不要跳过边界说明。** 每个类比后面都会写“这个比方不成立的地方”，那往往是事故高发区。

## 必交成果

- 退款链路的身份流转图，标注信任边界与凭据传递路径。
- 认证方式与 MFA、会话策略的选型对比表，含放弃项与理由。
- 令牌方案说明：JWT 声明设计、校验清单与过期/撤销策略。
- 权限矩阵与多租户隔离规则，覆盖客服、财务、运营等角色。
- Secret 与密钥的存放、轮换、应急轮转方案。
- 数据分级与脱敏清单，附威胁—对策对照。

## 完成规则

先完成十篇课程及其中的练习，再进入 `11-stage-assessment.md`。阶段测评达到 **80 分**视为掌握；**60–79 分**按测评给出的复习路线回到对应课程补课，补完后再测一次；**低于 60 分**需重新完成核心练习，从认证与授权基础重新梳理，再申请测评。
