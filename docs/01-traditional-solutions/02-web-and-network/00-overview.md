# Web 与网络

## 单元目标

学完本单元，你能把"页面打不开""接口 500""登录后又被踢出"这类模糊报障，还原成客户端、网络、服务端三段可验证的链路。

可以先借用查快递的经验：包裹没到，原因可能是地址写错（域名解析失败）、小区门卫不让进（防火墙拦截）、收件人不在家（端口没有服务监听），也可能是包裹本身装错了（HTTP 语义或数据格式出错）。只看"没收到"这一句，永远分不清是哪一种；只有沿着运输路径一段段查，才能得到可复现的结论。

本单元做的就是这件拆解工作：读懂 HTTP 报文与状态码，判断 TLS、Cookie、缓存、跨域这些机制在哪一步生效，并用 curl 与诊断工具留下证据。最终，你能为一项集成需求写出开发和运维都能照着执行的网络方案要点。

## 学习路线

预计学习时间为 **7–9 小时**。课程按以下顺序学习，每篇都配有练习：

1. [Web 架构与分层](01-web-architecture-and-layers.md)：客户端、服务端与网络分层，先建立全局地图。
2. [TCP/IP、DNS 与防火墙](02-tcp-ip-dns-and-firewall.md)：连接为何连不上，以及先查 DNS 还是先查端口。
3. [HTTP 请求与响应](03-http-request-response.md)：方法、报文结构与状态码的语义。
4. [Header、Cookie 与缓存](04-headers-cookies-and-caching.md)：会话如何维持、缓存为何命中失败。
5. [HTTPS、TLS 与证书](05-https-tls-and-certificates.md)：握手过程、证书校验与常见告警。
6. [JSON、XML、CSV 与字符编码](06-json-xml-and-encoding.md)：报文格式与乱码问题的边界。
7. [CORS、CSRF 与浏览器安全](07-cors-csrf-and-browser-security.md)：跨域预检、同源策略与请求伪造防护。
8. [curl 与网络诊断](08-curl-and-network-diagnostics.md)：用命令行复现问题并留存证据。
9. [反向代理、负载均衡与 CDN](09-reverse-proxy-load-balancer-cdn.md)：流量入口的职责划分与常见错配。
10. [Web 与网络阶段综合测评](10-stage-assessment.md)：检验本单元掌握程度。

这条路线不是随机排序，而是按"先看地图、再查道路、最后看门牌"组织的：

- **第 1–2 课先建立坐标。** 知道一次请求要经过哪些层，遇到"连不上"时才有地方落脚。
- **第 3–7 课进入报文内部。** 连接通了以后，真正决定业务对错的是方法、状态码、头部、证书和浏览器安全策略。
- **第 8–9 课练取证与入口。** 前七课解释"为什么"，这两课回答"怎么证明"和"流量入口该由谁负责"。
- **第 10 课只检验，不引入新知识。** 提前翻一眼测评范围，能帮你判断哪些课需要多练一次。

如果时间有限，不要跳读第 1、2 课。后面的缓存、跨域、代理问题，几乎都要靠这两课的分层视角才能讲清楚。

## 贯穿场景

晴空商城的退款流程要同时对接支付网关、订单服务与客服工单。用户提交退款后，客服看到"请求超时"，支付方看到"回调未达"，订单状态却停在"退款中"。

这正好是一组"三方都说自己没问题"的典型现场。本单元从网络侧面拆解它：请求在哪一层被截断，DNS 与防火墙是否放行，代理是否正确透传 Header，TLS 证书是否过期，回调地址是否被跨域与 Cookie 策略挡住，以及如何用 curl 逐跳验证。

同一组问题会在不同课里以不同角度出现。比如"退款回调没到"，在第 2 课看的是地址与放行，在第 5 课看的是证书，在第 9 课看的是代理与缓存。学完后你应该能把它们串成一条排查链，而不是记住十个孤立结论。

## 必交成果

- 一张端到端请求路径图，标注每层的排障命令与观测点。
- 一份退款接口的 HTTP 报文分析，含方法、状态码、关键 Header 与缓存策略判断。
- 一份 curl 复现脚本与诊断记录，证明故障发生在哪一跳。
- 一份跨域与登录态问题的成因说明及修复建议。
- 一份流量入口方案说明，涵盖反向代理、负载均衡与 CDN 的分工。

这些成果不要求写成正式文档，但不能只写结论。每条判断后面要能跟上一句"我是用什么命令、看到什么现象得出的"。

## 完成规则

先完成九篇课程及其中的练习，再进入阶段测评。测评达到 **80 分**视为掌握；**60–79 分**应按复习路线回到对应课程补课并重做练习；**低于 60 分**需重新完成核心练习后再测一次。

如果某篇的练习没有跑通，不建议直接做测评。测评里的场景题会默认你亲手抓过报文、算过分段耗时；只读不练，很容易把"看懂"误当成"会做"。
