# 课程导论

## 学习者

本课程面向会阅读和修改简单 Python 代码、但不了解企业后端和系统集成的学习者。

## 目标角色

课程培养 **AI 解决方案架构师**：既能理解业务和交付，也能设计传统系统与 AI 能力的组合。

## 学习顺序

先学传统解决方案，再学 AI 解决方案。这样学习者能理解 API、权限、数据、可靠性和运维如何约束 AI 系统。

## 学习方式

每篇文档都包含目标、场景、概念、实验、排错、测验和下一步。遇到代码时，先阅读整体流程，再逐行运行和修改。

## 范围

课程当前不建设第三个综合实战模块。综合实战将在两个知识模块稳定后另行设计。
