# 学习指南

## 推荐循环

1. 阅读学习目标和业务场景。
2. 用自己的话复述核心概念。
3. 运行最小示例并记录输出。
4. 完成实验和小测。
5. 根据答案解析回看薄弱章节。

## 进度记录

每完成一篇课，记录日期、完成的实验、仍不确定的术语和下一篇课程。不要只按阅读数量判断掌握程度。

## 标记含义

- `core`：核心必修。
- `card`：高频技术卡片。
- `advanced`：扩展专题。

**<u>不要跳过安全、失败处理和验收标准部分。</u>**它们决定方案能否进入生产。
