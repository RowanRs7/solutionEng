# 学习指南

## 先确定自己的起点

如果你会阅读和修改简单 Python 代码，但还不了解后端和系统集成，就从[课程导论](00-course-introduction.md)开始，按本页路线顺序学习。不要因为熟悉 Python 语法就直接跳到 AI 单元；后面的实验会用到 API、权限、数据和运行等前置概念。

如果你已经学过某个主题，可以先读该单元的学习目标并尝试练习或阶段测评。能独立解释和完成，再往后走；做不到就回到对应课程，不必把“以前看过”当作已经掌握。

每个单元都从 `00-overview.md` 开始，按概览页给出的顺序学习，并以该单元的阶段测评和完成标准检查掌握程度。具体课程入口见[知识地图](04-knowledge-map.md)。

## 推荐循环

每篇课都用同一个循环，减少“看懂了却做不出”的情况：

1. **读目标和场景。**先看学习目标和业务场景，写下这篇课要解决的一个问题。
2. **复述概念。**合上正文，用自己的话解释核心概念，再举一个场景中的例子。说不出来的地方就是要回看的位置。
3. **运行最小示例。**按步骤操作并记录实际输出，同时对照文档中的预期结果。先看清整体输入、处理和输出，再修改一个变量观察变化。
4. **完成实验和小测。**尽量先独立作答，再看答案解析。实验不仅记录成功结果，也记录失败现象和排查过程。
5. **按结果复习。**根据答案解析回看薄弱章节；如果只是碰巧答对，但无法解释其他选项为什么错误，也应重新阅读相关概念。

完成一篇课的标准不是“页面已经看完”，而是你能复述、能操作、能解释结果，并知道自己还有什么不确定。

## 进度记录

每完成一篇课，记录日期、完成的实验、仍不确定的术语和下一篇课程。可以给每篇留下四行简短笔记，方便下次继续，而不是只累计阅读数量。

遇到陌生概念时查[术语表](../reference/glossary.md)；实验出现异常时，先按[排障索引](../reference/troubleshooting-index.md)定位对应主题，再回到课程理解原因。每次只修改一个变量，并记录修改前后的现象。

## 标记含义

- `core`：核心必修，构成学习主线。
- `card`：高频技术卡片，适合集中建立概念或按需查阅。
- `advanced`：扩展专题，用于在主线之外继续深入。

**<u>不要跳过安全、失败处理和验收标准部分。</u>**它们决定方案能否进入生产。正常路径跑通，只说明“顺利时可以工作”；安全、异常和验收内容才能回答“出问题怎么办、由谁判断完成”。
